# Task 005 — Optional raw-data reprocessing for neutrophil recovery

## Status
PENDING / CONDITIONAL

## Trigger
Run only if an otherwise important dataset shows implausibly poor neutrophil recovery and Task 001 confirms raw sequencing/raw-droplet data can be obtained.

## Goal
Determine whether cell-calling/raw-processing choices materially improve recovery of genuine mature neutrophils.

## Requirements
- Dataset-specific plan approved before execution.
- Preserve original processed-matrix analysis as comparator.
- Document Cell Ranger/alternative versions and all cell-calling parameters.
- Quantify newly recovered cells, neutrophil marker coherence and QC characteristics.
- Do not tune solely to maximize neutrophil count.

## Output
A dataset-specific report and explicit recommendation on whether reprocessed cells should replace or supplement the phase-1 matrix.
